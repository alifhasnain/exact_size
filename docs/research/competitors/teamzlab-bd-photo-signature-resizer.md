## Core features
- Photo 300x300 px max 100 KB; signature 300x80 px max 60 KB, with custom tab `[Fact](https://tool.teamzlab.com/bd/photo-signature-resizer/)`
- Lowers JPEG quality only until under the limit; reports if limit is unreachable `[Fact](https://tool.teamzlab.com/bd/photo-signature-resizer/)`
- Signature "clean background" (whiten paper, darken ink) `[Fact](https://tool.teamzlab.com/bd/photo-signature-resizer/)`
- Claims browser-canvas processing, no upload, works offline after load (self-claim) `[Fact](https://tool.teamzlab.com/bd/photo-signature-resizer/)`
- BCS limits cross-checked in press: 300x300 / 100 KB photo, 300x80 / 60 KB signature `[Fact](https://en.prothomalo.com/youth/employment/xjgiumie3g)`

## UX strengths
Task-specific defaults for Bangladeshi forms; honest failure message when the limit cannot be met; Bangla labels.

## UX weaknesses / user complaints
No reviews found. Max-only KB (no minimum). English UI, no language switcher described. HEIC works only in Safari. No batch, no PDF. All from the vendor page.

## What they don't do (gaps)
Native app, batch, saved presets, min-KB floor, PDF, preset library beyond one form family.

## Takeaways for us
`[Hypothesis]` Closest regional analogue and a good feature bar (signature cleanup, honest errors). Web only, so a native offline app with a library is a clear step up.
