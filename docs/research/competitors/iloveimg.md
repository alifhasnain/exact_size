## Core features
- Compressor has no user-selectable target KB: it aims for maximum compression without visible loss `[Fact](https://www.iloveimg.com/help/faq)`
- Server-side: files are uploaded, then "completely deleted"; timing not specified `[Fact](https://www.iloveimg.com/help/faq)`
- Multi-file selection; plan limits apply `[Fact](https://www.iloveimg.com/help/faq)`

## UX strengths
Polished, familiar brand, many languages. `[Hypothesis]`

## UX weaknesses / user complaints
No review evidence gathered. Cannot hit an exact KB; uploads images; privacy wording vague (no named standard).
