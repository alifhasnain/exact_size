# Confirm the form list (phone version)

Open each link, check the numbers against the notice, and reply in chat. Nothing enters the app until you reply.

**How to reply:**
- All good: `confirm all, defaults OK`
- Some only: `confirm 1 2 3 6 7, defaults OK`
- With a fix: `confirm all except 5; 5: signature 4×2 cm` (or `drop 5`)

KB = file size. "KB-only" = the form gives no pixel size; the app fills only KB and format.
